# 套裝裝備取得與掉落資訊

以下保留原文的取得途徑與機率描述；「機率掉落」「低機率」「高機率」不代表確切掉落率。裝備名稱前省略套裝名稱時，以所在章節的套裝為準。

## 士兵套裝

主線任務獎勵中的士兵套裝裝備皆有機率取得。其他途徑如下：

| 裝備部位 | 取得途徑 |
|---|---|
| 護肩、披肩 | 風雷之森 Boss、遺忘丘陵 Boss、精靈之城 Boss，均為機率掉落 |
| 墜飾、劍、衣、褲、束帶、戒指 | 全地圖小怪有機率掉落；不包含 Boss |
| 盾、手套、護腕、靴 | 蘑菇森林 Boss、火焰森林 Boss，均為機率掉落 |
