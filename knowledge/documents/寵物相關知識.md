# 寵物相關知識

## 寵物 L 等級與寵物自身等級

「L 等級」用 L1、L2 等表示寵物階級；「寵物自身等級」是帶寵或吃經驗書時提升的等級，兩者不同。帶寵物是讓高轉數人物幫寵物提升自身等級、增加可用點，不會提升寵物 L 等級。玩家資料中的「8 轉 500 等」「8 轉 574 等」指人物轉數與人物等級。

## 取得寵物：成品、半成品或自行養成

玩家可直接購買已完成養成的成品寵物；購買價格較低、已有滿攻速的半成品寵物；或取得寵物後自行練成長值，再找高轉數玩家帶寵物自身等級。原攻略認為，找人帶寵物自身等級通常比在商城購買寵物經驗書便宜。

## 商寵、道具寵與最高成長值

道具寵指道具店販售的寵物；商寵指商城販售的寵物。寵物也可簡稱「寵」，例如 L1 商寵、L2 道具寵。不同類型、不同 L 等級的寵物作為被養成寵物時，最高成長值不同；同一 L 等級下，商寵的最高成長值高於道具寵。

下表是「被養成寵物」各 L 等級可達的最高成長值，不是飼料寵的成長值：

| L 等級 | 商寵／商城寵物（最高成長值） | 道具寵／道具店寵物（最高成長值） |
|---|---:|---:|
| L1 | 1.86 | 1.46 |
| L2 | 2.14 | 1.86 |
| L3 | 2.54 | 2.14 |
| L4 | 3.06 | 2.66 |
| L5 | 3.7 | 無此寵物 |
| L6 | 4.46 | 無此寵物 |

原文指出沒有 L5、L6 道具寵，因此也沒有 L5、L6 道具寵的最高成長值。

資料來源：https://discord.com/channels/702041515072946197/709674735402745907/709675887678980178

## 飼料寵與同化規則

「飼料寵」是拿來給目標寵物同化、提升成長值的材料寵。原文描述寶箱開出的飼料寵為交易綁定的商寵。飼料寵的類型與 L 等級會影響它能餵養的對象，以及被養成寵物可達的成長值。

- **道具寵作飼料**：飼料的 L 等級須高於被養成寵物的 L 等級。即使符合此條件，也無法只靠道具寵飼料練到最高成長值；被養成寵物是商寵或道具寵都一樣。
- **商寵作飼料**：原文寫飼料須達到被養成寵物「L 等級減 3」或更高，包含相差 3 級；符合時可把被養成寵物練到最高成長值，不分商寵或道具寵。

例如，養成 L3 道具寵並使用道具寵作飼料時，原文說須用 L4 以上的道具寵，但最多只能餵到成長值 1.94；之後須使用 L1 以上商寵繼續練。養成 L4 寵物時，由於沒有 L5 道具寵，原文建議改用 L1 以上商寵（L4−3＝L1）練成長值。

資料來源：https://discord.com/channels/702041515072946197/709674735402745907/709680688672145458

## 新手購買寵物與攻擊限制

原文指出寵物可發揮的攻擊力最多是人物攻擊力的 5 倍。例如人物攻擊力為 1000，即使寵物本身有 2 萬攻擊，能發揮的攻擊力仍受限於 5000；人物攻擊力提高到 4000 時，才可發揮該寵物的 2 萬攻擊力。

原攻略建議新手可先選滿攻速的半成品寵物。以 L3 寵物為例，原文描述只點約 4W 敏捷、不點力量的寵物有約 2.8W 攻擊；人物攻擊力約達 5600 以上時，才足以發揮寵物的全部攻擊。原文估計這類半成品價格約為成品的四分之一至三分之一，約 700 台幣以上。這些是原攻略的示例與價格估算。

## 寵物屬性、攻速與暴擊

寵物有力量、敏捷、幸運、智慧四種屬性及各自的成長值：

| 屬性 | 原文描述 |
|---|---|
| 力量 | 提供寵物攻擊力；若力量成長值為 2.0，每投入 1 可用點可增加 2 點力量 |
| 敏捷 | 提供寵物攻擊力與攻擊速度；若敏捷成長值為 2.0，每投入 1 可用點可增加 2 點敏捷 |
| 幸運 | 影響寵物暴擊率；原文建議約點到寵物自身等級 × 10，並視人物轉數調整 |
| 智慧 | 提供寵物攻擊力與魔力量；若智慧成長值為 2.0，每投入 1 可用點可增加 2 點智慧 |

寵物總攻擊力的算法：**點進去的力量數值 × 0.9＋寵物敏捷數值 × 0.7＋寵物智慧數值 × 0.8**。這裡的力量項指投入點數後得到的力量數值。

原文列出的各 L 等級攻速上限所需敏捷數值：

| 寵物 L 等級 | 敏捷數值 |
|---|---:|
| L1 | 80000 |
| L2 | 60000 |
| L3 | 40000 |
| L4 | 30000 |
| L5 | 25000 |
| L6 | 15000 |

資料來源：https://discord.com/channels/702041515072946197/709674735402745907/785595240160952340

## 寵物自身等級與每級可用點

人物帶寵或使用寵物經驗書，都可以提升寵物自身等級。寵物每升 1 級所得可用點取決於提供經驗的轉數，不是寵物 L 等級。原文提醒不同轉數的經驗不能混用。

| 提供經驗的轉數 | 寵物每升 1 級增加的可用點 |
|---|---:|
| 0 轉 | 3 點 |
| 1 轉 | 5 點 |
| 2 轉 | 8 點 |
| 3 轉 | 12 點 |
| 4 轉 | 15 點 |
| 5 轉 | 20 點 |
| 6 轉 | 28 點 |
| 7 轉 | 38 點 |
| 8 轉 | 50 點 |

寵物經驗書的原文對應關係：寵初提供 5 轉經驗、寵中提供 6 轉經驗、寵高提供 7 轉經驗、寵極提供 8 轉經驗。

資料來源：https://discord.com/channels/702041515072946197/709674735402745907/709682602407100418

## 寵物暴擊與帶寵服務

寵物暴擊與使用者轉數、寵物吃到的經驗轉數、寵物自身等級有關。原攻略建議幸運值約點到寵物自身等級 × 10；人物 5 轉以上時可達滿暴擊，4 轉以下則不一定。

找高轉數人物帶寵物自身等級，可增加每次升級得到的可用點。原攻略推薦找 7、8 轉玩家。以下人物提供收費帶寵服務；表中的轉數與等級均指玩家人物，不是寵物 L 等級：

## 寵物交易規則

一般情況下，L5、L6 寵物不開放交易。**L5 有付費交易例外**：解鎖神殿的捐獻等級後，可以付費將自己持有的 L5 寵物交易給另一位玩家；**每次交易都必須重新付費**，不限定整隻寵物只能交易一次。此條件不能套用到 L6 寵物。L4 寵物交易另要求交易雙方的人物轉數合計大於 9。

## 取得飼料寵

寵物可藉由同化飼料寵提高成長值。飼料寵可從寶箱取得；原文建議資源有限者每天在道具店買金寶箱，資源較充裕者可買金寶箱與奔雷寶箱。任務和虛空塔也可取得能開出寵物的寶箱。
