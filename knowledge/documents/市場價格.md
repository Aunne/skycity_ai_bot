# 市場價格與貨幣換算

資料來源：https://discord.com/channels/702041515072946197/702164547695411270

以下為原文記載的參考價格，實際交易價格可能變動。裝備表中的價格單位為天空石（TKS）；另有標明 R 或其他單位的項目依該列為準。

## 貨幣與數量縮寫

| 縮寫 | 意思 |
|---|---|
| T | 台幣 |
| R | 人民幣 |
| TKS／tks | 天空石 |
| TY／ty | 統御 |
| XB／xb | 星幣 |
| W／w | 萬 |
| E | 億 |

## 原文記載的換算關係

| 支付／投入 | 可換得 |
|---|---|
| 1 T（台幣） | 2.7 XB（星幣） |
| 1 R（人民幣） | 12.5 XB（星幣） |
| 2.5 R（人民幣） | 1E TKS（1 億天空石） |
| 1 TY（統御） | 1000 TKS（天空石） |

## 玩家間收購天空石的台幣參考價格

這是玩家間交易的**市場估算**，不是固定匯率或商店售價。原攻略記載約 **20 台幣（20 T）可向玩家收購 1E TKS（1 億天空石）**；實際可買到的數量會隨交易價格變動。
