[虛空塔相關知識]
虛空塔是天空之城的一個地圖,在溪明堡之內
虛空塔可以獲取天空碎片換取玄武朱雀套裝的商城件

2轉以上就可以進入虛空
4轉以前可以跟虛空車領一次噩夢級的低保
虛空車的意思是可以在虛空裡的boss殘血時進入虛空塔內,因為沒有打貢獻值因此只能領最低的獎勵俗稱低保
4轉之後可以領兩次噩夢級的低保與一次地獄級的低保

虛空塔需要打一定的貢獻值才會給天空碎片簡稱碎片,所以請一定要打滿貢獻值(跟虛空車的除外)

虛空塔建議需要使用超藥(一種高效率的補血瓶)與最低一套綁定的真5再去打
每天有三個時段會刷新:10點、16點、20點
每次刷新每個級別都有2次的免費進入次數，超過免費進入次數後的獎勵與碎片將大幅下降
因此建議每天刷免費次數即可


虛空噩夢最低配置 
```
血量  2.9W+
當前攻擊力 3576
進虛空後的攻擊力  5409
消耗的超藥量 291
花費時間    31分
```
新手打虛空注意事項
```
##  進虛空前請先問問裡面有沒有人 ex:  虛空噩夢1有人嗎?   ##
1. 進虛空後先打開背包刷新攻擊力
2. 只要王有兩隻小怪就會產生無敵護盾，建議小怪全部生成再一次擊殺(把小怪的重生CD拉到一致)，避免產生打地鼠現象，左邊小怪打完生右邊一直處於打小怪的狀態
3. 請盡量保持血量在2.7W以上，避免被一波帶走
4. 雷火神優先拿來打小怪
5. 當有看到紅色雷電球，建議不要使用三連擊，容易被紅色雷電球擊中
5. 多運用垂直走位躲避雷電球的攻擊( 紅色雷電球的優先躲避 )
```
