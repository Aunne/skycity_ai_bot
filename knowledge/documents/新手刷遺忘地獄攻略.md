# 新手刷遺忘地獄攻略

須達成條件(若未達成，則不建議嘗試):

1. 足夠強力的寵物，可以截圖發到群組請其他人幫你評估

2. 人物本身血量達25000以上，攻擊最少有3500以上佳

3. 三轉以上，因為可以進虛空塔提升攻擊力，讓刷地獄更輕鬆

4. 安裝補血腳本，也可以不用腳本，但會比較辛苦

5. 在youtube搜尋: 蒼神 天空之城，會有一部遺忘地獄跑圖的攻略，當然若不想刷遺忘的王就不用看了。


刷圖須注意事項:

1. 注意不要踩到昏眩毒蔓藤，此怪物足夠把你秒殺

2. 有兔怪優先擊殺兔怪，因為他可能會配合女妖，雷影等高爆發怪物出現，若被暈眩住，則基本上被秒殺了

3. 女妖是該副本威脅最大的怪物，遇到他時，由於該怪物特性是會追著你到背後攻擊，所以要一直保持走位的狀態，把他拉到沒有其他怪物的地方慢慢打，因此推薦女妖在殺完那個區域其他怪物後再進行擊殺

4. 雷火盡量都升到5級以上，如果遇到怪物過於密集的地方，可以先從外圍引怪慢慢殺

5. 打王前須完成的事:請把周圍的小怪清光再殺王

6. 鐵血守護神的攻略:基本上雷神範圍夠大的話，電完他以後，他會開始原地跺腳，與他抓大概三個人物的距離，開始橫向走位，與他保持距離，讓寵物不停輸出，如果還是不幸被暈眩到，則在他衝過來有傷害的瞬間再按補血，然後趕快離開，補完血後再重複剛剛的步驟
